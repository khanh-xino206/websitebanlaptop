- **Sinh viên thực hiện:** Huỳnh Tấn Phát
- **MSSV:** 501250508
- **Môn học:** Chuyên đề Frontend
- **Công nghệ sử dụng:** HTML5, Tailwind CSS, Font Awesome 6, JavaScript thuần.

---

## 📁 Cấu trúc thư mục

```text
laptop-html/
│
├── index.html                   # Trang chủ (Banner slider, Thương hiệu, Flash Sale, Laptop nổi bật)
├── san-pham.html                # Trang danh sách sản phẩm & bộ lọc (Hãng, Giá, CPU, RAM)
├── san-pham-chi-tiet.html       # Trang chi tiết cấu hình laptop, quà tặng & ảnh gallery
├── gio-hang.html                # Trang giỏ hàng, cập nhật số lượng, mã giảm giá
├── thanh-toan.html              # Trang xác nhận đơn hàng & phương thức thanh toán
├── dang-nhap.html               # Trang đăng nhập tài khoản khách hàng
├── dang-ky.html                 # Trang đăng ký thành viên mới
├── gioi-thieu.html              # Giới thiệu hệ thống showroom KTSHOP
├── lien-he.html                 # Trang liên hệ & bản đồ cửa hàng
│
├── admin/                       # Bộ giao diện trang Quản trị (Admin)
│   ├── index.html               # Dashboard tổng quan thống kê doanh thu & đơn hàng
│   ├── danh-sach-san-pham.html  # Bảng quản lý kho sản phẩm laptop
│   ├── them-san-pham.html       # Form thêm mới / cập nhật thông số laptop
│   └── danh-sach-don-hang.html  # Quản lý danh sách đơn hàng & duyệt đơn
│
└── images/                      # Thư mục hình ảnh banner và hình ảnh sản phẩm laptop
```

## 🚀 Cách mở giao diện
- Chỉ cần **nhấp đúp chuột (Double click)** vào file `index.html` hoặc bất kỳ file `.html` nào để mở trực tiếp trên Google Chrome, Cốc Cốc, Microsoft Edge mà không cần cài đặt thêm server hay node.js.
